# Webアプリ品質チェックリスト & 知見リファレンス

本スキルは、過去の不具合（片肺機能、UIとロジックの未結合、高校理科分類の混入、UTCタイムゾーンずれ、無効UI導線）を再発させないための実装前・実装後チェックリストです。

詳細な事故事例と再発防止策は [junior-vet-exam-chart/docs/LESSONS_LEARNED.md](../../junior-vet-exam-chart/docs/LESSONS_LEARNED.md) に記載されています。

---

## チェック項目

### 1. UIとロジックの完全結合
- [ ] ボタンを押した際、単に視覚が変わるだけでなく、実際のデータ（localStorage / IndexedDB）が更新・永続化されているか？
- [ ] 画面を再読み込み（リロード）しても、更新したデータが維持されているか？
- [ ] データ定義（動物の鳴き声、豆知識など）が画面の演出に100%反映されているか？

### 2. 双方向性の保証（エクスポート ⇆ インポート）
- [ ] データをファイル出力（書き出し）できる場合、そのファイルを読み込んで元の状態に完全復元できるインポートUIと処理があるか？
- [ ] バックアップ対象に、IndexedDBの全テーブルだけでなくlocalStorageの設定・進度も含まれているか？

### 3. 対象ユーザー（小学生）目線の用語統制
- [ ] 「生物・物理・地学・化学」などの高校理科分類が混入していないか？（「🧪 理科」「📐 算数」「🗾 社会」に統一されているか？）
- [ ] 機能名（「合格ドクター認定試験」等）が画面全体で統一されているか？
- [ ] カギやバッジなどのゲーム要素について、「どうやって集めるか」「集めたら何が起きるか」の説明が明記されているか？

### 4. タイムゾーン（JST: 日本標準時）の厳密性
- [ ] GitHub Actions（Ubuntu）はUTCである前提で、`Intl.DateTimeFormat` に `timeZone: 'Asia/Tokyo'` を指定しているか？
- [ ] バックアップ等のダウンロードファイル名の日付が日本時間の日付になっているか？

### 5. 無効なリソース・UIの非表示
- [ ] 画像やスキャン原本が存在しないモード（Stage 2など）で、不要な切り替えボタンが表示されていないか？

### 6. バージョン管理とリリース
- [ ] `package.json` のバージョンを引き上げたか？
- [ ] Git注釈付きタグ（`git tag -a vX.Y.Z -m "..."`）を作成し、リモートへプッシュしたか？
- [ ] 設定画面からキャッシュを完全パージして強制リロードできるか？
