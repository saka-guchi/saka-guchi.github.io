# フォントサイズ移行対応表 (font-size-map.md)

本ドキュメントは、「みならい獣医さんの中学受験カルテ」における旧フォントサイズ（10px〜32px）から新デザイントークンへのマッピングと、意図した視覚的強調が失われた箇所の整理です。

---

## 2. 意図した大きさが失われた箇所（特に数字を強調していた箇所）のリスト

CSS Moduleの単純一括置換により、本来「数値を大きく目立たせる（KPI・ゲーミフィケーション）」意図があった箇所が、周囲のラベルと同じサイズ（12px）に縮小された箇所を以下に特定しました。

| # | 画面・ファイル | 該当要素 | 旧サイズ / スタイル | 段階1-Aでの状態 | 推奨対応（1-Bでの専用トークン・スタイル復元） |
|---|---|---|---|---|---|
| **1** | `HomePage.tsx:322`<br>`HomePage.module.css:115` | **受験カウントダウン日数**<br>（`countdownNumber`） | `16px` / `font-weight: 900` | 12px に縮小 | `--font-size-subheading` (16px) または専用の強調クラス（`18px / 900`）を付与してカウントダウン日数を際立たせる |
| **2** | `HomePage.tsx:348`<br>`HomePage.module.css:151` | **合格カルテ完成度 %**<br>（`completionPercent`） | `18px` / `font-weight: 900` | 20px（見出し扱い） | バッジ内で他の文字（12px）と揃えるか、`16px / 900` でバッジの高さ内に美しく収める |
| **3** | `HomePage.tsx:945`<br>`HomePage.module.css:764` | **記憶キープ率 %**<br>（`retention-score`） | `13px` / `strong` | 12px に縮小 | プログレスバー横の数値として `13px / bold` を維持し、バーの高さとバランスを取る |
| **4** | `HomePage.tsx:1697-1710` | **単元数カウント**<br>（`80%以上: ○単元`） | `18px` / `font-weight: 800` | インライン style で 18px 維持中 | 1-BでCSSクラス化する際、`--font-size-heading` (20px) または `18px` で統計数値を明示 |
| **5** | `StudyPage.tsx:158`<br>`StudyPage.module.css:40` | **学習進捗カウンター**<br>（`counterText: 1 / 10`） | `14px` / `font-weight: 700` | 14px 維持 | 現在の進行度を示すため、現在の `14px` で適切 |
| **6** | `StudyPage.tsx:244`<br>`StudyPage.module.css:216` | **Recall First タイマー秒数**<br>（`meterCircle`） | `32px` / `font-weight: 900` | 特殊演出として 32px 維持 | タイマーサークル中央の巨大カウントダウンとして維持が妥当 |

## 3. 方針とまとめ
- 本文・見出し・補足の標準UIテキストは、4段階（20px, 16px, 14px, 12px）に厳格に集約します。
- 一方で、「残り日数（あと○日）」「完成度（○%）」「タイマー（○秒）」「得点（○問）」などの**動的な数値（KPI・ゲーミフィケーション要素）**については、一律で本文・補足サイズに落とすと子どもの達成感・視線誘導が損なわれるため、1-Bにおいて専用の数値クラス（`font-weight: 900` + 適切な強調サイズ）として意図的に保護・定義します。
