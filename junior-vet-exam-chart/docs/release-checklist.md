# リリース前チェックリスト & 保護者PIN初期設定ガイド

本ドキュメントは、アプリリリース時および実機導入時に実施する確認項目と、保護者向けPIN設定手順をまとめたものです。

---

## 1. 実機で保護者が今すぐPINを設定する手順（初回セットアップ）

お子さんが端末を使用する前に、保護者の方が以下の手順でPINを設定してください。

1. **アプリ起動**: ブラウザまたはPWAでホーム画面を開きます。
2. **保護者カルテを開く**: 画面上部の「👨‍⚕️ 保護者カルテ（指導医ログ）」ボタンをタップします。
3. **「こころの見守り」タブを選択**: タブバーから「こころの見守り」をタップします。
4. **未設定画面の確認**: 「🔐 保護者PINが未設定です」という案内画面が表示されます。
5. **長押し3秒で設定開始**:
   - 「🔒 保護者PINを設定する（長押し3秒）」ボタンを3秒間押し続けます。
   - ※うっかりタップや児童による誤操作を防止するための安全機構です。
6. **4桁のPINを2回入力**:
   - 「新しい4桁のPIN」にお好みの数字4桁を入力します。
   - 「もう一度入力（確認）」に同じ数字4桁を入力します。
7. **登録完了**:
   - 「PINを登録して解錠 ❯」をタップするとファンファーレ音とともに設定が完了し、見守り画面が開きます。
   - 以降、「こころの見守り」タブを開くたびにPIN認証が要求されます。
   - 画面最下部の「🛡️ セキュリティ操作履歴」に設定日時（JST）が記録されます。

## 2. セキュリティと安全運用上のルール

1. **うっかり防止の目的**:
   - 本機能は同一端末利用時における「うっかり見られてしまう事故」を防ぐための防御機構です。ブラウザの開発者ツールやストレージ直接操作に対する完全な暗号防壁ではありません。
2. **連続誤入力ロック（5回制限）**:
   - PINを5回連続で誤入力すると、**15分間の一時ロックアウト**が発動します。
   - 迂回操作を防ぐため、**ロックアウト中は「PINを忘れた場合」のリセット機能も実行不可**となります。
3. **PIN忘却時の救済手順（2段階確認）**:
   - ロックアウト解除後、画面下の「PINを忘れた場合（データをリセットして解除）」から救済リセットを実行できます。
   - リセット実行時、保護者PINと共有データ（お天気・お願い・伝えるカード）は初期化されますが、**お子さん専用のプライベート記録（private）および安全のための警戒サイン（careSignal）は絶対に消去されず保護されます（指示E案B承認仕様）**。
4. **データのバックアップについて**:
   - 設定画面の「学習履歴のバックアップ」「学習履歴の初期化」には、**お子さんのこころの記録（相談室・見守り・PIN）は一切含まれません**（案A承認仕様）。
   - ブラウザのサイトデータ削除や別端末への移行時はこころのデータは引き継がれませんのでご留意ください。
